# もぐらたたきミニゲーム

HTML / CSS / JavaScript だけで作った、ブラウザで遊べるシンプルなゲームです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「スタート」ボタンを押すとゲームが始まります。
3. 9つの穴のどこかに表示される「🐹（もぐら）」をクリックすると1点です。
4. 制限時間は30秒です。時間内にできるだけ高得点を目指してください。
5. ゲーム終了後は、メッセージに最終スコアが表示されます。もう一度「スタート」を押すと再プレイできます。

## ファイル構成

- `index.html`: 画面レイアウト
- `style.css`: 見た目（配色・配置・アニメーション）
- `script.js`: ゲームロジック（タイマー、ランダム表示、得点計算）
